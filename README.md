# cpsc-spring-332

# SET UP APPLICATION

1.  Install XAMPP and mySQL

2.  Clone the repository inside of XAMPP htdocs folder

3.  Open XAMPP and start Apache and mySQL (PATH: C:/xampp/htdocs)

4.  Open up your browser and go to localhost/Event_Manager_Project/AEM.php

5.  This will have created all of the tables for the database

6.  (optional) Go to localhost/Event_Manager_Project/add_dummy_data.php to add some dummy data to play with.

# START APPLICATION

7.  Go to localhost/cpsc-spring-332/index.php to start the application
